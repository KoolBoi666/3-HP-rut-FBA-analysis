# 3-HP-rut-FBA-analysis
Repository for the code and simulations for my research paper on 3-hydroxypropionic acid production in Escherichia coli through the Rut pathway, using flux balance analysis.

Google Colab link is provided along with the raw code.

This is part of my research paper and is linked in the paper.

The outputs are displayed along with the code, and further results are included in the files provided.

The results are purely simulations. No experiments were conducted.
